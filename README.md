# LUMEN — Люми

**LUMEN** — персональный голосовой помощник без генеративного ИИ на первом этапе. Сейчас в репозитории есть браузерный прототип и **отдельный подготовительный Command Engine**; новый каталог команд ещё не утверждён и движок пока не подключён к интерфейсу.

## Запуск

Node.js 20+ для тестов, внешних зависимостей нет:

```sh
npm test
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. При прямом открытии `file://` браузер может заблокировать JS-модули. Для Pages: Settings → Pages → **Deploy from a branch** → `main` / `(root)`. GitHub Actions не нужны.

## Что реально готово

- Web UI: чат, история в `localStorage`, ограниченные детерминированные демокоманды, ручной голосовой ввод при поддержке Web Speech API, необязательная озвучка.
- Отдельный `js/command-engine.js`: нормализация, строгое сопоставление шаблонов, типизированные параметры, права по умолчанию запрещены, явное подтверждение и проверяемый результат обработчика.
- Тесты движка используют только фикстуры. **Это не утверждённые команды Люми и пока не работающие действия на компьютере.**

## Ограничения

Нет LLM, облачного интеллекта, автономных решений и доступа к ОС. Web Speech API может пользоваться внешним сервисом браузера — гарантированно локальный голос планируется для Desktop и требует отдельной проверки. Не вводите в веб-демо секреты: история хранится в данном браузере. API-ключи никогда не помещаются в публичный клиент.

Лицензия пока не выбрана.
