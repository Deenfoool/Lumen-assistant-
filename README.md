# LUMEN — Люми

**LUMEN** — персональный голосовой помощник без генеративного ИИ на первом этапе. Сейчас в репозитории есть браузерный прототип и **отдельный подготовительный Command Engine**; категории 01 и 02 описаны как проектные спецификации; новый движок пока не подключён к интерфейсу, а Desktop-адаптеров ещё нет.

## Веб-демо и тесты

Node.js 20+ для веб-демо и тестов; для запуска только веб-версии внешних зависимостей нет:

```sh
npm test
python3 -m http.server 8000
```

Desktop-ресурсы: `npm run build:web` собирает разрешённые файлы интерфейса в `dist/` без документации проекта, системного исходного кода и секретов (кроме явно разрешённого `docs/ROADMAP.md`, на который ссылается UI). Сборка **не меняет корневые файлы Pages**.

Для Windows: `npm install`, затем `npm run desktop:dev`; установщик: `npm run desktop:build` в Windows при наличии Rust, C++ Build Tools и WebView2. См. [подробную инструкцию](docs/DESKTOP.md).

Откройте `http://localhost:8000/`. При прямом открытии `file://` браузер может заблокировать JS-модули. Для Pages: Settings → Pages → **Deploy from a branch** → `main` / `(root)`. GitHub Actions не нужны.

## Что реально готово

- Tauri 2 Desktop: отдельная нативная оболочка с **тем же интерфейсом**. Реализован только безопасный read-only мост и детерминированный координатор голосового сеанса; реальный локальный STT/TTS, захват микрофона и wake detector ещё не подключены. В Desktop браузерное распознавание речи отключено, чтобы не выдавать возможную внешнюю обработку за офлайн.
- Web UI: чат, история в `localStorage`, ограниченные детерминированные демокоманды, ручной голосовой ввод при поддержке Web Speech API, необязательная озвучка.
- `js/voice-session.js` — тестируемый координатор состояний голоса: разрешения, wake-префикс, 15-секундное окно, перебивание, отдельное отключение микрофона и TTS. Это не распознаватель речи и не аудиодвижок.
- Отдельный `js/command-engine.js`: нормализация, строгое сопоставление шаблонов, типизированные параметры, права по умолчанию запрещены, явное подтверждение и проверяемый результат обработчика.
- Каталог категории 02 содержит **26 намерений и 210 примеров произношения** в отдельном JSON-корпусе. Проверки корпуса не заменяют испытания распознавания речи и системных действий.
- Тесты движка используют только фикстуры. **Это тестовая механика, а не готовые действия на компьютере. Утверждение спецификаций не означает их реализации.**

## Ограничения

Нет LLM, облачного интеллекта, автономных решений и доступа к ОС. Web Speech API может пользоваться внешним сервисом браузера. Для Desktop основной кандидат распознавания — локальный мультиязычный Whisper через whisper.cpp; sherpa-onnx рассматривается для VAD, wake detection и локального TTS. Модели ещё не загружены и не интегрированы. См. [план голосового движка](docs/VOICE_ENGINE.md). Не вводите в веб-демо секреты: история хранится в данном браузере. API-ключи никогда не помещаются в публичный клиент.

Лицензия всего проекта пока не выбрана.
