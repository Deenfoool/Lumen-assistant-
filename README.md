# LUMEN — Люми

**LUMEN** — открываемый в браузере прототип персонального помощника «Люми» и основа будущей Desktop-платформы. Первый этап работает локально, без облачного ИИ и без доступа к системным командам.

- [Демонстрация GitHub Pages](https://deenfoool.github.io/Lumen-assistant-/) — после включения Pages (Deploy from a branch → main → /(root)).
- [Дорожная карта](docs/ROADMAP.md)
- [Архитектура и ограничения](docs/ARCHITECTURE.md)

## Быстрый старт

Откройте `index.html` в современном браузере или запустите любой статический HTTP-сервер в корне репозитория. Для проверки команд: `npm test` (Node.js 20+; установка пакетов не требуется). Сборка и GitHub Actions не нужны.

## Реализовано в 0.1–0.2

Адаптивная русскоязычная оболочка, локальный чат с явно ограниченными командами, подсказки, история в браузере, кнопка микрофона при наличии Web Speech API, озвучивание ответов через доступный браузерный синтез речи. Голосовые функции зависят от браузера и могут использовать сторонние службы распознавания. Это **не** LLM и **не** постоянное прослушивание.

## Безопасность

Не вводите секреты в демо: чат локально сохраняется в localStorage. Команды ограничены и не запускают программы компьютера; управление ОС относится к будущему Desktop-приложению с подтверждением чувствительных действий. Не храните API-ключи в коде GitHub Pages.

Лицензия пока не выбрана.
