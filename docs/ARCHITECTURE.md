# Архитектура LUMEN

## Текущий срез (0.2)
```
index.html + styles.css
        |
     js/app.js  — UI, localStorage, Web Speech API (по нажатию)
        |
 js/commands.js — детерминированный чистый обработчик локальных запросов
```

Веб-версия работает на статическом хостинге, не требует сборки, не содержит секретов, не вызывает внешнюю модель. Её команды намеренно ограничены; ссылки выдаются пользователю для самостоятельного открытия. Публичные GitHub Pages не подходят для хранения API-ключей.

История (до 50 последних сообщений) сохраняется на устройстве в localStorage с ключом lumen.messages.v1. Не используются аналитика или собственный сервер. Web Speech API в некоторых браузерах может передавать голосовые данные провайдеру браузера. Включение микрофона — только по нажатию; постоянного прослушивания нет. Озвучивание выключено по умолчанию.

## Целевая архитектура
```
Web UI (GitHub Pages)             Desktop shell
        |                              |
        +------ Lumen protocol --------+
                       |
             Dialogue orchestrator
              /       |        \
       Model gateway  Memory   Skills registry
                       |        |
               Permissions / approvals
                       |
               OS and external adapters
```

**Web**: визуальный клиент и ограниченные возможности браузера. **Desktop**: системные интеграции и, при необходимости, локальная модель. **Gateway**: отдельный доверенный бэкенд, если выбрана облачная модель. **Skills**: явные схемы входов/выходов, белые списки операций и подтверждения перед опасными/необратимыми действиями. Общий протокол отделяет ассистента от интерфейса.

## Безопасность и честность статусов
- Не запрашивать и не сохранять ключи облачной модели на публичном клиенте.
- Не использовать `eval`, произвольные shell-команды или выполнение текста модели.
- Не считать браузерные голосовые API гарантированно офлайн.
- Не объявлять управление ОС работающим, пока Desktop действительно не выполняет и не подтверждает соответствующие действия.
- Будущая память: экспорт, просмотр, очистка, ограничение срока хранения и отдельное разрешение для чувствительных данных.

## Локальная разработка
`npm test` — Node.js 20+; зависимостей нет. Для сайта можно открыть `index.html` через статический HTTP-сервер: `python3 -m http.server 8000`, затем `http://localhost:8000/`. ES-модули могут не работать при открытии как file:// в некоторых браузерах. GitHub Pages: источник **Deploy from a branch**, ветка **main**, папка **/(root)**. Не добавлять GitHub Actions.
