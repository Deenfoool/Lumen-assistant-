# Голосовой движок LUMEN

**Статус:** координатор сеанса реализован и тестируется. Реальный аудиозахват, STT, wake detector и TTS ещё не подключены. Голос Windows пока не считать работающим.

## Уже утверждённые требования

- Wake-активация: «Люми» и «Эй, Люми»; включается только явным действием пользователя и после разрешения микрофона.
- После установки микрофон выключен.
- После ответа — 15 секунд на следующую команду без повторения имени.
- Короткие ответы, возможность перебивать речь, русский язык.
- Постоянно не хранить аудиозаписи.
- «Стоп» прерывает озвучивание, но не отменяет ожидающее действие; «Отдыхай» закрывает диалог и отменяет ожидающее подтверждение; «Отключи микрофон» выключает захват и wake.
- Никаких LLM, генерации команд или передачи аудио в облако.

Полный контракт: [COMMAND_CATALOG.md](COMMAND_CATALOG.md).

## Рекомендация после сравнения движков

### Основной speech-to-text (STT): whisper.cpp + Whisper large-v3-turbo

**Основной кандидат — `whisper.cpp` с мультиязычной моделью `large-v3-turbo-q5_0`.** Она предназначена для распознавания множества языков, включая русский и английский; квантованный файл занимает около 574 MB. Код и веса Whisper опубликованы под MIT-лицензией. Источники: [официальный репозиторий whisper.cpp](https://github.com/ggml-org/whisper.cpp), [список моделей и размеров](https://github.com/ggml-org/whisper.cpp/blob/master/models/README.md), [карточка Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo).

Почему этот вариант подходит LUMEN:

- Один мультиязычный распознаватель вместо переключения между отдельными русской и английской моделями.
- Лучший кандидат из рассмотренных для смешанной фразы вроде «Люми, открой Task Manager и найди проект BrickLab».
- Работает локально, поддерживает Windows, CPU-only режим и несколько вариантов ускорения GPU.
- Реализован на C/C++; для Tauri сначала проверить интеграцию через Rust binding [whisper-rs](https://docs.rs/whisper-rs/latest/whisper_rs/) и сборку на Windows. Если binding создаст проблемы, использовать отдельный долгоживущий native-процесс, а не запускать новый процесс и заново загружать модель на каждую команду.
- Модель не нужна для непрерывного распознавания всего окружения: после wake/VAD она обрабатывает короткий завершённый речевой фрагмент.

**Ограничение:** Whisper не является лёгким постоянно работающим wake-word детектором. Он может ошибаться на именах программ, акцентах и шуме; поддержку смешанной RU/EN-речи необходимо подтвердить на нашем наборе команд. `large-v3-turbo-q5_0` — стартовый баланс качества и размера, а не обещание одинаковой скорости на любом ПК.

### Другие варианты

| Движок | Сильные стороны | Почему не основной выбор |
|---|---|---|
| **faster-whisper** | Использует семейство Whisper; есть режим мультиязычного распознавания по сегментам, оптимизация через CTranslate2. | Требует Python-окружения и усложняет поставку приложения Tauri. Хороший запасной вариант для сравнительного теста, но не самый простой нативный путь. |
| **sherpa-onnx** | Локальные потоковые модели, VAD, API для микрофона и TTS; есть русская потоковая модель T-one. | Найденная русская streaming-модель ориентирована на русский, поэтому её нельзя считать проверенным единым решением для произвольного переключения русского и английского внутри одной фразы. Оставить в стеке для VAD/KWS/TTS и как резерв для низкой задержки. [Документация](https://k2-fsa.github.io/sherpa/onnx/). |
| **Vosk** | Небольшие модели, низкие требования к ресурсам, настраиваемый словарь у ряда моделей. | Каталог предлагает отдельные русские и английские модели; лёгкие модели заметно уступают по точности большим. Для англоязычных названий в русской команде это менее подходящий первый выбор. [Каталог моделей](https://alphacephei.com/vosk/models). |
| **Облачные STT API** | Могут дать хорошее качество без локальной нагрузки. | Не подходят требованиям приватности и офлайн-работы: аудио не должно покидать компьютер. |

### Native-интеграция в Tauri

1. Захват микрофона — нативный Desktop-адаптер с явным состоянием разрешения.
2. VAD — локальный детектор речевой активности, чтобы не гонять большую STT-модель на тишине.
3. Wake word — отдельный локальный keyword-spotting компонент. У sherpa-onnx есть KWS API, но поддержку русского для «Люми» / «Эй, Люми» нужно проверить экспериментально. Не считать Whisper полноценным энергоэффективным wake detector.
4. После активации и окончания фразы — whisper.cpp с `large-v3-turbo-q5_0`; в тестах сравнить с `medium` или `small`, если целевой ПК не обеспечивает приемлемую задержку.
5. Текст передаётся в существующий детерминированный Command Engine. STT только распознаёт текст и **не** выбирает произвольные действия.
6. Ответ формируется по правилам LUMEN и передаётся в локальный TTS.

Если русскоязычный wake detector окажется ненадёжным, безопасный fallback — явная кнопка/горячая клавиша активации, пока не будет проверена подходящая локальная модель. Не включать микрофон по умолчанию и не переключаться скрытно на Web Speech API.

## Text-to-speech (TTS)

Для русского голоса оставить кандидатом `vits-piper-ru_RU-irina-medium` через sherpa-onnx. Для английской речи подобрать отдельную английскую Piper-совместимую модель. Каталог Piper содержит голоса для более чем 30 языков: [документация sherpa-onnx Piper](https://k2-fsa.github.io/sherpa/onnx/tts/piper.html).

Перед включением в установщик проверить качество обоих голосов, произношение английских названий внутри русских ответов и лицензию каждой конкретной модели. Лицензия runtime и лицензия голосовых весов — разные вещи. TTS должен поддерживать отмену текущего воспроизведения и настройки громкости/скорости независимо от системной громкости.

## План проверки качества

Собрать фиксированный тестовый корпус из реальных фраз и вариантов произношения из каталога команд. Обязательно включить:

- русские команды с английскими именами: «Люми, открой Task Manager»;
- смешанные фразы: «Найди backup в Downloads», «Запусти VS Code и открой BrickLab»;
- полностью английские короткие команды;
- похожие названия, шум, разные микрофоны, быстрый темп и паузы;
- фразы, которые не должны запускать действие.

Сравнить Whisper large-v3-turbo-q5_0, меньшую Whisper-модель и sherpa-onnx на одной записи. Измерить точность распознавания, время от конца фразы до текста, потребление RAM/CPU, ошибки на английских названиях и ложные активации. Выбор считать окончательным только после теста на целевой Windows-машине.

## Контракт модулей

~~~text
локальный аудиозахват
       |
       +--> VAD / wake detector (wake включается явно)
       |
       +--> локальный STT --> финальный текст
                               |
                         VoiceSession
                               |
                    строгий Command Engine
                               |
                      результат / ошибка
                               |
                         короткий ответ
                               |
                         локальный TTS
~~~

`js/voice-session.js` — детерминированный координатор состояний. Он проверяет opt-in и разрешение микрофона, обрабатывает префикс «Люми» только в начале, управляет 15-секундным окном, прерыванием, отключением микрофона и раздельными настройками голоса. Он **не** записывает звук, не распознаёт речь, не озвучивает самостоятельно и не исполняет системные действия. Native-адаптер должен передавать ему финальные транскрипты и подтверждать фактическое завершение TTS.

## Безопасность и приёмка

- Микрофон выключен после установки; wake включается только после явного согласия.
- Отзыв разрешения немедленно закрывает захват, выключает wake и сбрасывает ожидающее подтверждение.
- Не сохранять сырое аудио; не включать скрытую телеметрию.
- Во время TTS обеспечить echo suppression либо надёжный режим barge-in; если полного дуплекса нет, честно показать ограничение и оставить кнопку/горячую клавишу.
- Проверить ложные активации, шум, разные микрофоны, «Люми, пока», речь во время ответа, 15-секундный таймер, отсутствие реакции при MIC_OFF, работу без сети после загрузки моделей.
- До завершения тестов не обещать «всегда слушает», «полностью офлайн» или «можно перебить» в Windows-приложении.
